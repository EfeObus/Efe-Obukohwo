Zodiac Real Estate AI

ML-Powered Property Analytics Platform

May 2025 – Aug 2025 Full Stack Developer Internship Team Lead (5 developers)

The Challenge

Zodiac Tech Toronto needed a comprehensive real estate analytics platform that could:

  • Process and analyze 49,551+ Canadian property listings in real-time
  • Predict property values with high accuracy for investment decisions
  • Integrate live economic data (interest rates, inflation, market trends)
  • Identify undervalued properties automatically
  • Handle high API traffic with enterprise-grade security

Business Goal

Create a platform that gives real estate investors an analytical edge by combining machine learning predictions with real-time economic indicators, all accessible through a modern API and web interface.

Machine Learning Pipeline

The core prediction engine uses an ensemble of three models:

Ensemble Architecture

  • XGBoost – Gradient boosting for structured property features
  • LightGBM – Fast training on large datasets with categorical features
  • Random Forest – Robust baseline with feature importance analysis

Final predictions are weighted averages of all three models, reducing variance and improving generalization.

Feature Engineering

  • Property features: Bedrooms, bathrooms, square footage, lot size, year built, property type
  • Location features: Neighborhood, proximity to transit, school ratings, crime data
  • Economic features: Bank of Canada interest rates, local unemployment, population growth
  • Market features: Days on market, price history, comparable sales

Security Implementation

Enterprise-grade security was a core requirement. I implemented:

  • 5-Tier API Key System – Different access levels for free, premium, and enterprise users
  • ML-Powered XSS/CSRF Protection – Pattern recognition for malicious payloads
  • Behavioral Analysis – Detecting and blocking suspicious request patterns
  • Rate Limiting – Tiered limits based on API key level
  • Input Validation – Strict schema validation on all endpoints

Security Outcome

Achieved 100% attack prevention rate during penetration testing, with zero successful XSS, CSRF, or injection attacks.

Investment Intelligence Features

  • Undervalued Property Detection – Automated identification of properties priced below model predictions (85% accuracy)
  • Portfolio Optimization – Risk-adjusted recommendations based on user investment criteria
  • Market Trend Analysis – Real-time integration with Bank of Canada and Statistics Canada APIs
  • Comparable Sales Analysis – Automated comp selection and adjustment
  • Investment Score – Composite metric combining appreciation potential, rental yield, and market stability

My Role & Leadership

As Team Lead managing 5 developers, I was responsible for:

  • Architecture Design – Designed the full-stack architecture and ML pipeline
  • ML Model Development – Built and tuned the ensemble prediction system
  • API Development – Implemented 20+ RESTful endpoints with documentation
  • Security Implementation – Designed and built the security middleware stack
  • Team Coordination – Daily standups, code reviews, sprint planning

  • Documentation – API docs, architecture diagrams, deployment guides

Key Learnings

  • Ensemble models outperform single models – The 88.3% accuracy came from combining three models, each contributing unique strengths
  • Real-time economic data matters – Property predictions improved 12% when we added Bank of Canada interest rate features
  • Security as a first-class feature – Building security from day one is far easier than retrofitting
  • API performance requires constant monitoring – Optimizing database queries kept response times under 400ms
