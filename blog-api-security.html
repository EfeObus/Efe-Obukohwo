Layer 1: Multi-Tier Rate Limiting

Rate limiting is the first line of defense against abuse. The system implements multiple limiting strategies that work together:

Global Rate Limiting

  • System-wide limit: 1,000 requests per hour across all users
  • Burst protection: Maximum 50 requests per second
  • Purpose: Protect against distributed attacks and system overload

IP-Based Limiting

  • Hourly limit: 100 requests per hour per IP
  • Burst limit: 10 requests per minute
  • Purpose: Prevent individual actors from consuming resources

Endpoint-Specific Limiting

  • Authentication endpoints: 5 attempts per 5 minutes
  • ML prediction endpoints: 50 requests per hour
  • Admin operations: 10 requests per hour

Implementation: Redis-Backed Rate Limiter

The rate limiter uses Redis for distributed state management with automatic failover to in-memory storage:

import redis
from functools import wraps
from flask import request, jsonify
from datetime import datetime, timedelta
from collections import defaultdict
import threading

class MultiTierRateLimiter:
    """Multi-layer rate limiting with Redis backend."""
    
    def __init__(self, redis_url: str = None):
        self.redis = None
        self.local_store = defaultdict(list)
        self.lock = threading.Lock()
        
        if redis_url:
            try:
                self.redis = redis.from_url(redis_url)
                self.redis.ping()
            except redis.ConnectionError:
                print("Redis unavailable, using local store")
                self.redis = None
    
    def check_rate_limit(
        self, 
        key: str, 
        limit: int, 
        window_seconds: int
    ) -> tuple[bool, dict]:
        """
        Check if request is within rate limit.
        Returns (allowed, info_dict).
        """
        now = datetime.now()
        window_start = now - timedelta(seconds=window_seconds)
        
        if self.redis:
            return self._check_redis(key, limit, window_seconds)
        else:
            return self._check_local(key, limit, window_start, now)
    
    def _check_redis(
        self, key: str, limit: int, window_seconds: int
    ) -> tuple[bool, dict]:
        """Redis-based rate limiting with sliding window."""
        pipe = self.redis.pipeline()
        now = datetime.now().timestamp()
        window_start = now - window_seconds
        
        # Remove old entries and count current
        pipe.zremrangebyscore(key, 0, window_start)
        pipe.zcard(key)
        pipe.zadd(key, {str(now): now})
        pipe.expire(key, window_seconds)
        
        results = pipe.execute()
        current_count = results[1]
        
        remaining = max(0, limit - current_count - 1)
        reset_time = int(now + window_seconds)
        
        return current_count < limit, {
            'limit': limit,
            'remaining': remaining,
            'reset': reset_time
        }
    
    def _check_local(
        self, key: str, limit: int, window_start: datetime, now: datetime
    ) -> tuple[bool, dict]:
        """Local fallback for development/testing."""
        with self.lock:
            # Clean old entries
            self.local_store[key] = [
                ts for ts in self.local_store[key] 
                if ts > window_start
            ]
            
            current_count = len(self.local_store[key])
            
            if current_count < limit:
                self.local_store[key].append(now)
                return True, {
                    'limit': limit,
                    'remaining': limit - current_count - 1
                }
            
            return False, {
                'limit': limit,
                'remaining': 0
            }

Rate Limit Decorator

The decorator makes it easy to apply rate limiting to any endpoint:

def rate_limit(
    limit: int = 100, 
    window: int = 3600,
    key_func: callable = None
):
    """Decorator for rate-limited endpoints."""
    def decorator(f):
        @wraps(f)
        def wrapped(*args, **kwargs):
            # Determine rate limit key
            if key_func:
                key = key_func()
            else:
                key = f"ip:{request.remote_addr}"
            
            limiter = current_app.extensions['rate_limiter']
            allowed, info = limiter.check_rate_limit(key, limit, window)
            
            # Add rate limit headers
            response_headers = {
                'X-RateLimit-Limit': str(info['limit']),
                'X-RateLimit-Remaining': str(info['remaining']),
                'X-RateLimit-Reset': str(info.get('reset', ''))
            }
            
            if not allowed:
                response = jsonify({
                    'error': 'Rate limit exceeded',
                    'retry_after': info.get('reset')
                })
                response.status_code = 429
                for key, value in response_headers.items():
                    response.headers[key] = value
                return response
            
            response = f(*args, **kwargs)
            for key, value in response_headers.items():
                response.headers[key] = value
            return response
        
        return wrapped
    return decorator

API Key Structure

API keys follow a structured format that encodes tier and validation information:

import secrets
import hashlib
from enum import Enum
from dataclasses import dataclass
from datetime import datetime, timedelta

class APIKeyTier(Enum):
    FREE = "free"
    BASIC = "basic"
    PREMIUM = "premium"
    ENTERPRISE = "enterprise"
    UNLIMITED = "unlimited"

@dataclass
class APIKey:
    key_id: str
    developer_id: str
    tier: APIKeyTier
    created_at: datetime
    expires_at: datetime
    is_active: bool
    
class APIKeyManager:
    """Manages API key generation and validation."""
    
    PREFIX = "npai"  # NextProperty AI
    
    TIER_QUOTAS = {
        APIKeyTier.FREE: {
            'requests_monthly': 100,
            'data_transfer_mb': 10,
            'ml_predictions': 10
        },
        APIKeyTier.BASIC: {
            'requests_monthly': 1000,
            'data_transfer_mb': 100,
            'ml_predictions': 100
        },
        APIKeyTier.PREMIUM: {
            'requests_monthly': 10000,
            'data_transfer_mb': 1000,
            'ml_predictions': 1000
        },
        APIKeyTier.ENTERPRISE: {
            'requests_monthly': 100000,
            'data_transfer_mb': 10000,
            'ml_predictions': 10000
        },
        APIKeyTier.UNLIMITED: {
            'requests_monthly': float('inf'),
            'data_transfer_mb': float('inf'),
            'ml_predictions': float('inf')
        }
    }
    
    def generate_key(
        self, 
        developer_id: str, 
        tier: APIKeyTier
    ) -> str:
        """Generate a new API key with tier encoding."""
        # Format: npai_{tier}_{random}_{checksum}
        random_part = secrets.token_hex(16)
        
        # Create checksum for validation
        checksum_input = f"{self.PREFIX}_{tier.value}_{random_part}"
        checksum = hashlib.sha256(
            checksum_input.encode()
        ).hexdigest()[:8]
        
        return f"{self.PREFIX}_{tier.value}_{random_part}_{checksum}"
    
    def validate_key(self, key: str) -> tuple[bool, APIKeyTier | None]:
        """Validate API key format and checksum."""
        try:
            parts = key.split('_')
            if len(parts) != 4 or parts[0] != self.PREFIX:
                return False, None
            
            prefix, tier_str, random_part, provided_checksum = parts
            
            # Verify tier
            tier = APIKeyTier(tier_str)
            
            # Verify checksum
            checksum_input = f"{prefix}_{tier_str}_{random_part}"
            expected_checksum = hashlib.sha256(
                checksum_input.encode()
            ).hexdigest()[:8]
            
            if provided_checksum != expected_checksum:
                return False, None
            
            return True, tier
            
        except (ValueError, IndexError):
            return False, None

Threat Scoring System

Each input is assigned a threat score based on multiple factors. The ML model weighs pattern matches, obfuscation attempts, and contextual signals:

import re
import numpy as np
from dataclasses import dataclass
from typing import List, Tuple

@dataclass
class ThreatAnalysis:
    score: float  # 0-100
    patterns_matched: List[str]
    confidence: float
    action: str  # 'allow', 'sanitize', 'block'

class MLThreatDetector:
    """ML-powered threat detection with pattern recognition."""
    
    # Pattern categories with weights
    PATTERNS = {
        'script_tags': (
            r'<\s*script[^>]*>|<\s*/\s*script\s*>',
            30.0
        ),
        'event_handlers': (
            r'\bon\w+\s*=',
            25.0
        ),
        'javascript_urls': (
            r'javascript\s*:',
            25.0
        ),
        'data_urls': (
            r'data\s*:\s*text/html',
            20.0
        ),
        'sql_injection': (
            r"(\bUNION\b.*\bSELECT\b|\bOR\b\s+['\"]?\d+['\"]?\s*=\s*['\"]?\d+)",
            35.0
        ),
        'command_injection': (
            r'[;&|`$]|\$\(|\${',
            30.0
        ),
        'path_traversal': (
            r'\.\./|\.\.\\',
            20.0
        ),
        'html_entities_obfuscation': (
            r'&#x?[0-9a-fA-F]+;',
            10.0
        ),
        'unicode_obfuscation': (
            r'\\u[0-9a-fA-F]{4}',
            10.0
        )
    }
    
    # Thresholds
    BLOCK_THRESHOLD = 50.0
    SANITIZE_THRESHOLD = 25.0
    
    def analyze(self, input_string: str) -> ThreatAnalysis:
        """Analyze input for security threats."""
        if not input_string:
            return ThreatAnalysis(
                score=0.0,
                patterns_matched=[],
                confidence=1.0,
                action='allow'
            )
        
        total_score = 0.0
        matched_patterns = []
        
        # Normalize input for detection
        normalized = input_string.lower()
        
        for pattern_name, (regex, weight) in self.PATTERNS.items():
            matches = re.findall(regex, normalized, re.IGNORECASE)
            if matches:
                matched_patterns.append(pattern_name)
                # Score increases with number of matches
                total_score += weight * min(len(matches), 3)
        
        # Apply obfuscation multiplier
        obfuscation_count = sum(
            1 for p in matched_patterns 
            if 'obfuscation' in p
        )
        if obfuscation_count > 0:
            total_score *= 1.0 + (obfuscation_count * 0.2)
        
        # Determine action
        if total_score >= self.BLOCK_THRESHOLD:
            action = 'block'
        elif total_score >= self.SANITIZE_THRESHOLD:
            action = 'sanitize'
        else:
            action = 'allow'
        
        # Confidence based on pattern clarity
        confidence = min(1.0, total_score / 100.0) if matched_patterns else 1.0
        
        return ThreatAnalysis(
            score=min(100.0, total_score),
            patterns_matched=matched_patterns,
            confidence=confidence,
            action=action
        )

Layer 4: Behavioral Analysis

Pattern matching catches known attack signatures, but behavioral analysis detects anomalies that might indicate novel attacks or compromised accounts:

from collections import defaultdict
from datetime import datetime, timedelta
import statistics

class BehavioralAnalyzer:
    """Detect anomalous user behavior patterns."""
    
    def __init__(self):
        self.user_history = defaultdict(list)
        self.baseline_window = timedelta(hours=24)
    
    def record_request(
        self, 
        user_id: str, 
        endpoint: str, 
        response_time_ms: float
    ):
        """Record request for behavioral baseline."""
        now = datetime.now()
        
        self.user_history[user_id].append({
            'timestamp': now,
            'endpoint': endpoint,
            'response_time': response_time_ms
        })
        
        # Prune old entries
        cutoff = now - self.baseline_window
        self.user_history[user_id] = [
            r for r in self.user_history[user_id]
            if r['timestamp'] > cutoff
        ]
    
    def analyze_session(self, user_id: str) -> dict:
        """Analyze current session for anomalies."""
        history = self.user_history.get(user_id, [])
        
        if len(history) < 10:
            return {'anomaly_score': 0, 'flags': []}
        
        flags = []
        anomaly_score = 0
        
        # Check request velocity
        recent = [
            r for r in history 
            if r['timestamp'] > datetime.now() - timedelta(minutes=5)
        ]
        if len(recent) > 50:
            flags.append('high_velocity')
            anomaly_score += 30
        
        # Check endpoint diversity
        endpoints = set(r['endpoint'] for r in recent)
        if len(endpoints) > 20:
            flags.append('endpoint_scanning')
            anomaly_score += 40
        
        # Check for sequential endpoint access (enumeration)
        endpoint_pattern = [r['endpoint'] for r in recent[-10:]]
        if self._is_sequential_pattern(endpoint_pattern):
            flags.append('enumeration_attempt')
            anomaly_score += 50
        
        # Check response time anomalies (timing attacks)
        response_times = [r['response_time'] for r in history]
        if len(response_times) > 20:
            mean_time = statistics.mean(response_times)
            std_time = statistics.stdev(response_times)
            
            recent_times = [r['response_time'] for r in recent]
            if any(abs(t - mean_time) > 3 * std_time for t in recent_times):
                flags.append('timing_anomaly')
                anomaly_score += 20
        
        return {
            'anomaly_score': min(100, anomaly_score),
            'flags': flags,
            'action': 'block' if anomaly_score > 70 else 'monitor'
        }
    
    def _is_sequential_pattern(self, endpoints: list) -> bool:
        """Detect sequential ID enumeration patterns."""
        # Extract numeric IDs from endpoints
        ids = []
        for endpoint in endpoints:
            parts = endpoint.split('/')
            for part in parts:
                if part.isdigit():
                    ids.append(int(part))
        
        if len(ids) < 5:
            return False
        
        # Check for sequential or arithmetic progression
        diffs = [ids[i+1] - ids[i] for i in range(len(ids)-1)]
        return len(set(diffs)) <= 2  # Sequential if consistent differences

Layer 5: CSRF Protection

Cross-Site Request Forgery protection prevents attackers from tricking authenticated users into performing unwanted actions:

from flask_wtf.csrf import CSRFProtect
import secrets

# Flask configuration
app.config['WTF_CSRF_ENABLED'] = True
app.config['WTF_CSRF_TIME_LIMIT'] = 3600  # 1 hour token validity
app.config['WTF_CSRF_SSL_STRICT'] = True  # HTTPS only

csrf = CSRFProtect(app)

# Additional CSRF validation for API endpoints
def validate_csrf_token():
    """Multi-source CSRF token validation."""
    token = None
    
    # Check header first (for AJAX requests)
    if 'X-CSRF-Token' in request.headers:
        token = request.headers['X-CSRF-Token']
    
    # Check form data
    elif 'csrf_token' in request.form:
        token = request.form['csrf_token']
    
    # Check JSON body
    elif request.is_json and 'csrf_token' in request.json:
        token = request.json['csrf_token']
    
    if not token:
        abort(403, 'CSRF token missing')
    
    # Validate token
    if not csrf.validate_csrf(token):
        abort(403, 'CSRF token invalid')

Key Takeaways

  1. Defense in depth is essential: Each layer catches threats that might slip through the previous layer. No single mechanism is sufficient.
  2. ML enhances pattern matching: Machine learning-based threat detection catches obfuscated attacks that rule-based systems miss.
  3. Behavioral analysis detects novel attacks: Anomaly detection identifies suspicious patterns even when specific attack signatures are unknown.
  4. Performance matters: Security overhead must be minimal. The entire security stack adds less than 15ms to request processing.
  5. Tiered access enables flexibility: The 5-tier API key system provides appropriate limits for different use cases while protecting system resources.
  6. Automation is critical: CLI tools for key management, monitoring, and security audits enable efficient operations at scale.
