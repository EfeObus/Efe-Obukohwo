# Efe Obukohwo - Portfolio Website

A modern, responsive portfolio website built with HTML, CSS, and JavaScript featuring a sleek black, gold, and white color scheme. The portfolio uses a multi-page structure for better organization and user experience.

## Features

- **Multi-Page Structure**: Organized content across separate pages for better navigation
- **Responsive Design**: Fully responsive across all devices
- **Modern Animations**: Smooth transitions, fade-in effects, and interactive elements
- **Professional Sections**:
  - Home page with hero section and profile
  - About page with statistics and background
  - Experience page with detailed work timeline
  - Education page with academic qualifications
  - Certifications page with professional credentials
  - Skills page with categorized expertise
  - Projects page with featured work
  - Contact page with form and social links
- **Performance Optimized**: Fast loading with optimized assets
- **Interactive Elements**: Hover effects, smooth transitions, and dynamic content

## Page Structure

- `index.html` - Home page with hero section
- `about.html` - About me and statistics
- `experience.html` - Work experience timeline
- `education.html` - Educational background
- `certifications.html` - Professional certifications
- `skills.html` - Technical skills and expertise
- `projects.html` - Featured projects
- `contact.html` - Contact information and form

## Setup Instructions

1. Open `index.html` in your web browser
2. Customize the content with your personal information
3. Replace placeholder images with your actual photos/project images
4. Update contact information and social media links
5. Modify the projects section with your actual work

## Customization

### Personal Information
- Update the hero section with your name and title
- Modify the about section with your background
- Update contact information in the contact section

### Images
Replace the following placeholder images:
- `profile-placeholder.jpg` - Your profile photo
- `about-placeholder.jpg` - About section image
- `project1-placeholder.jpg` - Project screenshots
- `project2-placeholder.jpg`
- `project3-placeholder.jpg`

### Content
- Skills: Update the skills grid with your technologies
- Projects: Add your actual projects with descriptions and links
- Social Links: Update with your social media profiles
